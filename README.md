# Sleight of Mind

An AI capability-elicitation eval, starting with chess. Can a language model play at a rating you choose, or does it give itself away?

Live site: https://yashrao10.github.io/sleight-of-mind/

This is a pilot. All figures are preliminary until the full set of 117 positions is scored. The site is a single static page (`index.html`). The Play board uses chess.js from a public CDN, and its opponent is a random stand-in for now.
